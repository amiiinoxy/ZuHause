# Komplettes Paket herunterladen

1. Auf dieser Branch-Seite **Code** und dann **Download ZIP** wählen:
   https://github.com/amiiinoxy/Mein-Projekt/tree/abgabe-lahntal-2026
2. Das heruntergeladene ZIP auf dem Rechner vollständig entpacken.
3. Im entpackten Ordner **Lahntal** die Datei **Lahntal_A2.pdf** öffnen.
4. Für die Weiterbearbeitung in QGIS **Lahntal.qgz** öffnen. Die Unterordner `daten`, `fotos` und `symbole` dabei zusammen mit der Projektdatei belassen.

Direkter ZIP-Download (bei privatem Repository vorher bei GitHub anmelden):
https://github.com/amiiinoxy/Mein-Projekt/archive/refs/heads/abgabe-lahntal-2026.zip

Die Karte hat DIN A2 quer und Maßstab 1:65 000. Quellen, Lizenzen und fachliche Einschränkungen stehen in **Quellen_und_Methodik.pdf**. Die Lizenzen der jeweiligen Geodaten und Fotos sind in diesem Begleitnachweis angegeben; eine Lizenzdatei im Repository-Stamm ersetzt diese individuellen Lizenzen nicht.

Die Ausgangsdaten, Originalfotos, Verarbeitungsskripte, Karten-PDF und das bearbeitbare QGIS-Projekt sind in diesem Ordner enthalten. Diese Dateien liegen auf dem Branch `abgabe-lahntal-2026`.
